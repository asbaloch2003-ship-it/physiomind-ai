# Feedback collection setup

The Feedback page already posts to Supabase using a server-only service role key. To activate durable storage, create a private table named `project_feedback` with columns: `id` (uuid primary key, generated), `created_at` (timestamp with timezone, default now), `role` (text), `rating` (integer), `area` (text), `comment` (text), and `contact` (nullable text). Enable row-level security and do not add public read policies. Configure server-side `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in Vercel Environment Variables. Never expose the service role key as a client-side variable. Redeploy, submit a test response, and confirm it appears in the Supabase Table Editor before inviting students. The form will show an error rather than falsely claim success when storage is unavailable.
